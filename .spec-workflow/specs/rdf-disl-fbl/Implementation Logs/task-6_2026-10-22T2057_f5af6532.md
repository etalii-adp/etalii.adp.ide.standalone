# Implementation Log: Task 6

**Summary:** Task 6 bundles the four DISL definitions w3c-rdf, w3c-owl, w3c-skos and w3c-shacl from etalii-adp/etalii.adp into src/diagrams/rdf/definition/, with their companions and provenance. They were bundled with the existing bundle-disl.sh, not by hand. The module embeds them and its own binding w3c-turtle.fbl, which has the same bytes as the conformance copy (re-vendored at etalii.adp 7a1b166). RdfDefinitions loads the four as one BundledDefinitionSet and the binding as w3c-turtle.fbl#turtle, and gives each reading its definition and the wire ids of its own x- block. The four document factories now return the binding's template through TemplateWriter. RdfLocalName is gone; the old factories are kept as test-only Parity/TodaysNewDocuments. Every base name gives the factory's former bytes except two: {key} folds a hyphen to '_' and puts '_' before a leading digit (my-graph becomes ex:my_graph, 2026 plan becomes ex:_2026_plan). RdfNewDocumentsTests pins this and the pull request names it. The RdfEmptyDocument hostile name lost its '/', since a base name holds no path separator. New tests are BundledDefinition, RdfBinding and RdfNewDocuments, each seen to fail first. Gates ran in a freshly created worktree; all were green except the macOS-only UndoRedoFlow test. CI is green.
