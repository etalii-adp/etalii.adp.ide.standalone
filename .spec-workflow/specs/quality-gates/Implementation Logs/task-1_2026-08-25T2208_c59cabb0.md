- **Methods:** MirroredRules (IReadOnlyDictionary<string, IReadOnlyList<string>>) - ADP rule id to the Structurizr rule ids it answers for; one-to-many because Structurizr names a rule per element kind while ADP names one per question, AdpOnlyRules (IReadOnlyDictionary<string, string>) - ADP's editing-surface rules with no Structurizr counterpart, each with why it has none, NotImplementedRules (IReadOnlyDictionary<string, string>) - Structurizr rules ADP does not implement, each naming what would have to exist first (workspace.scope, model.softwaresystem.documentation, model.softwaresystem.decisions), MirroredStructurizrRules (IReadOnlySet<string>) - the flattened Structurizr side, for filtering a verdict
