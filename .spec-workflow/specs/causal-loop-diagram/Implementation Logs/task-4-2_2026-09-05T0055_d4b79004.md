# Implementation Log: Task 4.2

**Summary:** The bounded separation pass and the honest refusal. A converged self-organizing map does not guarantee non-overlap and Requirement 6.5 does, so phase two pushes overlapping boxes apart in document order for a bounded number of rounds (200), along whichever axis needs the least movement so the arrangement phase one worked out is not undone. If overlaps survive the rounds the layout refuses for that document, naming the size and handing back nothing to draw. The rounds are a parameter of Compute so the refusal is reachable from a test rather than only from a document nobody has written yet — a refusal nothing can trigger is a refusal nobody has checked. The extent ratio is deliberately not the guard, and there is a test that says so: a 24-variable complete graph is shown scoring between 1:1 and 3:1 on the ratio it would have been judged by, and being judged on intersection instead. 29 layout tests, ten sabotage-verified defects — one of which survived the first attempt and produced a new test.
