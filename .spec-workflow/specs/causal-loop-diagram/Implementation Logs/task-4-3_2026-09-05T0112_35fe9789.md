# Implementation Log: Task 4.3

**Summary:** The arrangement persisted as authored positions, and the diagram-wide action that invokes it. ArrangeCausalLoopCommand runs the self-organizing layout and writes the result into the registration's layout: block through RegistrationLayout, the same mechanism a drag uses — no new persistence. The body is never touched, so a .cld reviewed in a pull request shows no diff at all. It is ONE command rather than one SetRegistrationLayoutCommand per box, because undoing a forty-variable arrangement in forty undos is not what "one undo away like every other edit" means; the inverse is a byte-exact registration restore, the same shape the body's own restore uses. The action is offered on a placement — the canvas with nothing selected, which is where the diagram itself is the subject — and nowhere else, satisfying Requirement 6.1's "diagram-wide context action the user invokes, never what happens when a document opens". 22 new tests, eight sabotage-verified defects.

### Classes

#### ArrangeCausalLoopCommand / ArrangeCausalLoopCommandHandler
- **Purpose:** Runs SelfOrganizingLayout over the body and stores every variable's centre into the registration's layout: block, keyed by the element id a drag reports (variable:{id}). Refuses in the layout's own words when the layout refuses, and writes nothing in that case. On an IO failure part-way it restores the registration before reporting, so a half-written block is never what the user is left looking at.
- **Location:** src/diagrams/causal-loop/backend/EtAlii.Adp.Diagram.CausalLoop/Commands/ArrangeCausalLoopCommand.cs
- **Exported:** No

#### RestoreCausalLoopRegistrationCommand / handler
- **Purpose:** Puts a registration back byte for byte — the inverse of an arrangement. A whole-file snapshot rather than a reversing edit, for the same reason the body's restore is one: an arrangement touches many entries at once and a snapshot cannot be wrong about what it is putting back.
- **Location:** src/diagrams/causal-loop/backend/EtAlii.Adp.Diagram.CausalLoop/Commands/ArrangeCausalLoopCommand.cs
