# Implementation Log: Task 4.1

**Summary:** Meyer's self-organizing graph layout with all three sources of randomness replaced: initial positions from a phyllotaxis spiral in document order, stimuli from a two-dimensional Halton sequence computed from the iteration index alone, and tie-breaking by document order. Fixed iteration count (2000), learning-rate and neighbourhood-radius schedules that read only the iteration index, no wall-clock and no RNG anywhere. The neighbourhood is measured in GRAPH hops (BFS over undirected links), which is what makes this a graph layout rather than a clustering of points; an unreachable variable is not pulled at all, so disconnected components arrange separately. Runs behind the drawn-element budget (1000), declining before it starts rather than running slowly. 19 tests, ten sabotage-verified defects. The two-process determinism test earned its keep under measurement, not by assertion: a per-process string hash shifting the stimulus rectangle is invisible to all seventeen same-process tests — including the one that computes the layout twice in one process — and is caught only by the child-process comparison.

#### Integration
- **Description:** Random initial positions become a phyllotaxis spiral indexed by the variable's position in document order, scaled by the widest box so a diagram of long names starts wider. Arbitrary best-matching-unit tie-breaking becomes document order, enforced by strictly-less-than so the earlier index keeps the win.

#### Integration
- **Description:** The neighbourhood is hops over an undirected reading of the links. Undirected on purpose: causality has a direction and the drawing shows it, but two variables joined by an arrow belong near each other regardless of which way it points, and a directional reading would put a variable that only ever causes at infinity from everything downstream. Unreachable is -1 and is treated as its own thing rather than as a large number, so a variable in another component is not pulled at all.
