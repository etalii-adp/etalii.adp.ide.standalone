# Implementation Log: Task 16

**Summary:** AnsibleSession (internal) and AnsibleSessionFactory. The factory resolves the diagram's subject as the folder the .adp sits in - this type's one genuine novelty - preferring registrationPath over bodyPath even though the router makes them the same file for a bodyless type, because the registration is the file that made the folder a diagram and is the one to trust if they ever diverge. The session Acquires the folder from the store for its lifetime and Releases on DisposeAsync, subscribes to the store's Changed, and turns each announced re-read into Remove-then-Add via the mapper's Diff against what it last delivered. Per-connection state is the viewport and the delivered set, nothing else - the project itself stays shared. Three things worth recording. (1) MoveElementAsync refuses with a sentence ("...drawn from the folder's own files... Move a role by moving its folder."), never throwing and never quietly succeeding: the seam returns a reason string precisely so a type that cannot do a thing can say so in the user's terms. A test asserts the disk is byte-identical after the refusal, because a refusal that still touched a file is the bug actually worth guarding. (2) NEITHER type takes an IHistoryStack, and a reflection test asserts the factory's constructor has no History-typed parameter. Not "takes one and never uses it" - the missing parameter IS the statement, and a test is what stops someone adding it back for symmetry with the other modules. (3) TwoSessions_BothKeepHearing_WhenOneOfThemCloses pins task 12's Acquire/Release split end to end: one connection closing must not leave the other's diagram quietly stale. One build error on the way: ShortGuid's factory is NewShortGuid(), not New(). Verified: build 0 errors; module 116/116.
