# Implementation Log: Task 6

**Summary:** RestoreDocumentCommand gained an optional After (the text its edit left). With it, the handler refuses to overwrite a file another program changed and returns CommandResult.Outdated; HistoryStack then drops every entry on both sides bound to that document and keeps the rest. Differs from the design, which said clear on reload: the history is per project and the reload path cannot tell an outside write from the host's own restore, so stale steps are dropped when an undo would act on them, for that file only. Existing modules pass no After and are unchanged. Guards seen to fail with the check and the drop disabled, then 71 of 71. Commit 72a0dea0, PR 154.
