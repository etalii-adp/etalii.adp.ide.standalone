## Artifacts

### API Endpoints

#### gRPC server-streaming etalii.adp.WorkspaceService/Watch
- **Purpose:** The one long-lived stream a tab holds: context, hierarchy and diagram deltas as members of WorkspaceMessage
- **Location:** src/backend/EtAlii.Adp.Diagram/WorkspaceService.cs
- **Request Format:** WatchWorkspaceRequest { project_id, watch_id }
- **Response Format:** stream WorkspaceMessage { oneof hierarchy | context | diagram }

#### gRPC unary etalii.adp.WorkspaceService/OpenDiagram
- **Purpose:** Starts a diagram's pump on the connection's Watch under a client stream id; refuses with PermanentRefusal codes, Unavailable when no Watch is open
- **Location:** src/backend/EtAlii.Adp.Diagram/WorkspaceService.cs
- **Request Format:** OpenDiagramStreamRequest { stream_id, OpenDiagramRequest request }
- **Response Format:** OpenDiagramStreamResponse {}

#### gRPC unary etalii.adp.WorkspaceService/CloseDiagram
- **Purpose:** Stops one diagram stream; closing a gone stream is not an error
- **Location:** src/backend/EtAlii.Adp.Diagram/WorkspaceService.cs
- **Request Format:** CloseDiagramStreamRequest { watch_id, stream_id }
- **Response Format:** CloseDiagramStreamResponse {}
