# Implementation Log: Task 4

**Summary:** Task 4 adds GestureConstraintEvaluator.Connect, which gives the first refusal of a connect gesture in the order of DISL 8.4 (std.endpoints, std.multiplicity, std.acyclic, then the declared connect rules). Each built-in is worded by its refusal from constraints.builtIn (now read by DislConstraintReader into DislBuiltIn.Refusal) with violation bound, and by the runtime without one; a switched-off built-in refuses nothing; the cycle check is one reachability walk from the target. It also adds the fixed attribute of DISL 4.3: DislAttribute.IsFixed, FixedValue and ReadOnlyReasons, read at load; the fixed value is read by DislElement while has() is false, ignored by DislModelBuilder, never written by DislWrite, shown read-only by FormDerivation and refused by FormCommit. New tests ConnectRefusal.Tests.cs (13) and FixedAttribute.Tests.cs (5), seen to fail first against a stub and sabotages. The rewritten definition loads with no diagnostics; no construct of finding A2 is still refused. Open: the library reads allowSelfLoops per declaration only, so a self-link is refused by the cycle check; put to the user. Pull request #571, merged as 61dd5e80c0b9c43974295b83330d1a2786b06ccd.
