### Classes

#### C4DocumentFactory
- **Purpose:** Produces the empty Structurizr DSL document a new C4 diagram starts from. Constructed with a DiagramOrigin and a C4ViewKind; six instances cover six types. An empty C4 model is not an empty file - every view except systemLandscape is a view *of* something - so it emits one placeholder softwareSystem named after the file for the view to be scoped to, plus a container when the kind is Component (a component view is scoped to a container) and a deploymentEnvironment when the kind is Deployment. File names are converted to valid DSL identifiers; quotes in names are escaped.
- **Location:** src/diagrams/c4/backend/EtAlii.Adp.C4/C4DocumentFactory.cs
- **Methods:** CreateEmptyDocument, ViewDeclaration, IdentifierFor, Escape
- **Exported:** No

#### C4CodeDocumentFactory
- **Purpose:** The c4/code factory, which throws NotSupportedException with a message naming the class/ER notation dependency. Registered so core's startup check passes; refuses so no half-notation ships. Exposes the message as the public const Unavailable so the canvas and tests share one wording.
- **Location:** src/diagrams/c4/backend/EtAlii.Adp.C4/C4CodeDocumentFactory.cs
- **Methods:** CreateEmptyDocument
- **Exported:** No

#### C4ViewKind
- **Purpose:** Enum of the six declarable C4 view kinds: SystemLandscape, SystemContext, Container, Component, Dynamic, Deployment. Deliberately has no Code member - the Structurizr DSL declares no code view and C4 advises against hand-drawing that level.
- **Location:** src/diagrams/c4/backend/EtAlii.Adp.C4/_Model/C4ViewKind.cs
- **Exported:** No

#### C4DocumentFactoryTests
- **Purpose:** Covers every view kind: workspace/model/views structure, balanced braces, the exact view declaration and scope per kind, the landscape having no focal system, the component view reaching to a container, the deployment environment existing, a dynamic view having no include *, file-name-to-identifier conversion including empty and all-punctuation names, quote escaping, and the code factory's refusal.
- **Location:** src/diagrams/c4/backend/EtAlii.Adp.C4.Tests/C4DocumentFactory.Tests.cs
