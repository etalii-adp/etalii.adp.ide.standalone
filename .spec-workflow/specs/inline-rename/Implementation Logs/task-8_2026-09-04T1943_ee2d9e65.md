#### Four defects found only by running the app
- **Purpose:** 1) The editor cancelled its own interaction the instant it appeared: a one-frame dialog whose teardown restored focus, which blurred the editor, which committed an unchanged value, which ended the interaction. 2) An empty placement registry read as 'the element has gone'. 3) StrictMode's double-invoked effects latched the editor's closing flag at first paint, so nothing could ever commit - the box appeared, took focus, accepted typing, and silently discarded every commit. 4) The editor sent a value the module had ALREADY refused, writing container "" into courier.dsl before it was undone; the justification for that behaviour was false, because ValidateAsync runs on propose and SubmitInteraction does not run it again. All four fixed, each with a test seen to fail for the right reason.
- **Location:** src/client/src/canvas/label/InlineLabelEditor.tsx, src/client/src/shell/context/ShellPromptHost.tsx
- **Exported:** No
