## Artifacts

### Classes

#### FdgParser
- **Purpose:** Reads a .fdg LineDocument into FdgModel, recording each entry's line range. NEVER THROWS - the noted divergence from dependency-graph's parser, which throws on non-YAML. An unknown key, type or malformed entry is passed over, kept in the text, and reported as an FdgProblem with its line. A mapping's End does not cover its children, so ranges are computed by a recursive EndMark over descendants; using node.End made SetKey insert duplicate keys, found by three failing tests.
- **Location:** src/diagrams/functional-decomposition-graph/backend/EtAlii.Adp.Diagram.FunctionalDecompositionGraph/FdgParser.cs
- **Methods:** Parse(LineDocument) -> FdgModel
- **Exported:** Yes

#### FdgWriter
- **Purpose:** Splices one entry's lines through LineDocument/LineSplice rather than re-serialising, so every other byte - quoting, key order, comments, blank lines, line endings - survives. Returns FdgEdit (WasApplied / Refusal).
- **Location:** src/diagrams/functional-decomposition-graph/backend/EtAlii.Adp.Diagram.FunctionalDecompositionGraph/FdgWriter.cs
- **Methods:** SetName, SetDescription, SetText, MoveTo, Resize, SetConnectionName, AddElement, RemoveElement, Connect, Disconnect
- **Exported:** Yes

#### FdgDocumentFactory
- **Purpose:** An empty document: header line `functional-decomposition-graph: 1`, `elements: []`, `connections: []`, in the requested line ending.
- **Location:** src/diagrams/functional-decomposition-graph/backend/EtAlii.Adp.Diagram.FunctionalDecompositionGraph/FdgDocumentFactory.cs
- **Methods:** EmptyDocument(lineEnding)
- **Exported:** Yes

#### FdgModel / FdgElement / FdgConnection / FdgProblem
- **Purpose:** The parsed model. Element and connection TYPES are strings, not enums, so an unknown type survives a read and is reported rather than lost. FdgElementTypes.All and FdgConnectionTypes are the enumerable vocabularies tests walk.
- **Location:** src/diagrams/functional-decomposition-graph/backend/EtAlii.Adp.Diagram.FunctionalDecompositionGraph/_Model/
- **Exported:** Yes
