### Integrations

#### Integration
- **Description:** Every gesture call from inside a canvas reports its refusal to the frame; streams report status to it.
- **Frontend Component:** useContextConnection (executeAction, executeShortcut, setProperty), useDiagramStream (moveElementTo, status), TextEditorPanel save, useCanvasRefusal
- **Backend Endpoint:** ContextService.ExecuteAction / SetProperty, DiagramService.MoveElement / Open / SaveText (gRPC)
- **Data Flow:** call sent -> reporter.attempted() clears the line -> outcome refused -> reporter.refused(error) -> CanvasFrame draws .canvas-rejection; stream loading/failed -> CanvasStatusReporter -> CanvasFrame draws .canvas-status
