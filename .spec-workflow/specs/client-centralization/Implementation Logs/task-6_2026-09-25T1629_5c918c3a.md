- **Frontend Component:** useLibrarySelection (librarySelection.ts), module canvases' definitions

- **Data Flow:** key/gesture/menu -> ActionInvoked -> backendKeyOf(definition, actionId) -> executeShortcut(contextShortcutOf(key), elementSourceOf(targetId)) -> refused ? action-refused{actionId, message} : nothing; then module onActionInvoked
