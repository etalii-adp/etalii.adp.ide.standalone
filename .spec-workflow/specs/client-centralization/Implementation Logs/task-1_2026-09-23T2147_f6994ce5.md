## Artifacts

### Functions

- **`contrastRatio(one, other)`** - `src/client/src/themeContrast.ts`. WCAG 2.x contrast ratio between two hex colours. **The one implementation in the repository, deliberately:** an acceptance number stated as a ratio is only meaningful if everyone computes it the same way, and two implementations are two acceptance criteria wearing one name. Architect 2 held a sketch outside the repository and withdrew it in favour of this.
- **`relativeLuminance(colour)`** - WCAG 2.x relative luminance; throws on anything that is not hex.
- **`themeTokens(indexCss)`** - parses `index.css` into light and dark token maps. Dark is a `@media (prefers-color-scheme: dark)` block redeclaring a subset, so a dark token falls back to its light declaration exactly as the cascade does. **The first thing in the client to read the dark block at all.**
- **`resolveToken(tokens, name)`** - resolves a token to its literal in one theme, following `var()` indirection. **Does not honour the `var(--x, fallback)` fallback, deliberately:** a fallback is what makes an undefined token invisible in review, and a guard that read it would measure the literal rather than the theme - it would have passed green against every defect this task fixed.
- **`tokensRead(css)`** - every `var(--token)` a stylesheet reads. The name pattern is `[A-Za-z0-9_.-]` because `[a-z0-9-]` silently truncated `--vscode-editorWidget-background` to `--vscode-editor`: **the count was right and the names were wrong.**
