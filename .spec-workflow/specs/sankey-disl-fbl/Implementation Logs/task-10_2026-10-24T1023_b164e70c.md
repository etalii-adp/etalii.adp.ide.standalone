# Implementation Log: Task 10

**Summary:** Read the Sankey body through its FBL binding; the binding is offered in etalii.adp by #503 (merged at 0991d1b). SankeyBody opens the body through sankey.fbl at FBL 0.5 (every slot read: "text", rules match mappings only, a computed written attribute for one-line flow-mapping entries). SankeyReader turns the reading into the module's model and the reader's nine sentences, word for word on the same lines. The DISL model is built by DislModelBuilder from the binding's reading, so SankeyDisl is gone. The store, validator, edit handler and arrange read through SankeyReader; the new-document template is the binding's. A body YamlDotNet refuses still opens empty and read-only with the same sentence. SankeyParser moved to the tests as Parity/HandWrittenSankeyReader, the oracle. Tests: SankeyReader.Tests (corpus parity, nine sentences on their lines, not-yaml and duplicate-key read-only, written text kept, dangling ends kept, never throws) and SankeyRoundTrip.Tests (unchanged save keeps the bytes, undrawn entries kept).
