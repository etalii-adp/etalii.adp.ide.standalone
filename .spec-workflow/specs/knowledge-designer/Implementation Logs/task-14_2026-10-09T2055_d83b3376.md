# Implementation Log: Task 14

**Summary:** Column headers: menu, adding, reordering, resizing. header/columnActions.ts is the menu as data: columnMenuGroups(column, definition, {raise, startRename}) returns the entries the definition offers (TableDefinition.columnActions: rename, changeType, filter, sortAscending, sortDescending, group, hide, wrap, insertLeft, insertRight, duplicate, delete) in four groups for the shell's ContextMenu; plus addableKinds, defaultKind, dropIndex, resizedWidth, MINIMUM_COLUMN_WIDTH (60). header/ColumnHeader.tsx: a press on the header button opens the menu, a drag moves the column, a drag of the right border (role separator) resizes, rename is an input in the header. header/AddColumn.tsx: the + after the last column, in an extra 40px track of the header row only, outside the grid's column count. GESTURES raised (all through onGesture; a refusal shows on the table's own line): renameColumn { columnId, values: [name] }; setColumnType { columnId, settings: { type } }; addFilter { columnId }; addSort { columnId, settings: { direction: ascending|descending } }; groupBy { columnId }; hideColumn { columnId }; setColumnWrap { columnId, settings: { wrap: 'true'|'false' } }; addColumn { settings: { type } } from the +, or { targetId, settings: { side: left|right, type: defaultKind } } from the menu; duplicateColumn { columnId }; deleteColumn { columnId }; moveColumn { columnId, index: its place among the VISIBLE columns after the move }; resizeColumn { columnId, settings: { width: pixels as text } }. TableKindDefinition.addable = false keeps a kind out of the + and out of Change type; TableDefinition.defaultKind names what an inserted column starts as. The title column's hide and delete are disabled with a reason. A table that is read-only, or given no onGesture, has no menu, no border handle and no +. The first visible column carries class table-cell-first in header and rows, which the stylesheet makes sticky. Reused: shell/context/ContextMenu and canvas/gesture/usePointerGesture, and the pointer() test helper of canvas/library/testing/canvasHarness. A DEFECT FOUND BY THE TESTS before commit: the resize measured each move from the width already drawn, which follows the pointer, so the distance was added twice; fixed by keeping the width at grab (grabbedWidthRef). Seen to fail: a resize that raises on every pointer move (2 tests). DEVIATION: ColumnMenu.tsx of the task's file list does not exist; the menu is the shell's ContextMenu fed by columnActions.ts. Not verifiable under jsdom and left for the browser pass (task 32): that the first column really stays put, the drop position against real layout, and the menu's placement.
