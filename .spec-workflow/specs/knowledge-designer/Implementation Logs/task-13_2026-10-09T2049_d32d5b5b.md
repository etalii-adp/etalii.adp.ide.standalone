# Implementation Log: Task 13

**Summary:** Cell editors and the keyboard. cells/keyboard.ts: keyOutcome(key, at, bounds) returns move | edit (with the typed character as 'replace') | newRow | clear | none, and tabTarget for reading order; arrows, Home/End (with Ctrl or Cmd for the table's ends), PageUp/PageDown by ten, Tab/Shift+Tab, Enter and F2 to edit, Shift+Enter for a new row, Delete/Backspace to clear; a shortcut with Ctrl/Cmd and a letter is left alone. cells/CellEditor.tsx: InputCellEditor for the kinds text, number (a text input with decimal inputMode, so the backend says what a number is), date, datetime (datetime-local) and time; ListCellEditor on the new components/SearchList.tsx for 'option' (one), 'options' (several) and 'rows' (related rows; never offers to create). A kind's editor is named by the module's definition: TableKindDefinition.editor (TableEditorKind); a kind without one is shown and never edited. 'checkbox' has no editor: Enter or a double click toggles it. Gestures raised through TableEvents.onGesture, which now returns Promise<string> (the refusal, or ''): setCell { rowId, columnId, values, settings? } where an emptied cell sends values [], a checkbox 'true'/'false', a list the option or row ids, and creating an option sends settings { newOption: text } beside the values it is added to; addRow { targetId: the row the keys are on }. An unchanged value sends nothing. A refusal inside an editor keeps it open with the reason (role alert, aria-invalid); a refusal of a direct gesture (tick, clear, new row) shows on the table's own line. Enter commits and stays, Tab commits and moves, Escape cancels, blur commits without taking the focus back; after Escape the blur is ignored (settledRef). The surface: one cell has tabIndex 0 (roving), aria-selected marks the active cell, the focus follows it and the scroll keeps it in sight; a read-only table and a group heading are not edited. CONVENTION for the module (task 17 onward): the candidates of a relation column are sent as that column's options; a value not among them keeps the label its cell carries. DEVIATION: 'one editor per value kind' is two components, one over the browser's inputs parameterised by kind and one over the search list, not nine files. Seen to fail: the editor committing on the blur after Escape (the cancel test fails). Not done: no range selection, copy or paste; PageUp/PageDown move ten rows rather than a screen; the list editor is positioned under the cell by CSS only and is not checked in a real browser yet (task 32's pass).
