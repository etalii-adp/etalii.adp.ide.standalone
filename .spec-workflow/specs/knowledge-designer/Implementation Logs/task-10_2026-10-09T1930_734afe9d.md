# Implementation Log: Task 10

**Summary:** The table model, the session seam and the wire. src/api/designers.proto gives the designer family five unary calls (OpenTable, CloseTable, SetTableWindow, SetTableView, Edit) and the table messages; WorkspaceMessage gained member 4, `table` (TableStreamMessage: baseline, change, ended), so a table rides the tab's one Watch stream under a client-generated stream id that shares the connection's id space with diagram streams. EtAlii.Adp.Designer holds the model that names no designer type (TableModel/: TableBaseline, TableColumn, TableOption, TableView, TableViewSettings, TableSort, TableFilterGroup/TableCondition, TableFinding, TableRow, TableCell, TableChange = TableRowsChanged | TableStructureChanged | TableFindingsChanged | TableEditSettled, TableGesture) and the seam IDesignerSession (Baseline, Changed, SetWindow, SetActiveView, Edit(editId, gesture) returning an error sentence or empty) and IDesignerSessionFactory (Origin, Open(watchId, rootPath, registrationPath, bodyPath)). DEVIATION in placement: DesignerService, DesignerSessionFactories, TableStreams and TableWire live in EtAlii.Adp.Diagram, beside WorkspaceService and its connections, exactly as EditorService and EditorSessionFactories do; designers.proto is compiled there into namespace EtAlii.Adp.Designer.Wire. The write-behind ruling is carried by the contract: Edit answers when the edit is accepted, TableCell.Pending marks an unwritten value, and TableEditSettled (wire TableEditOutcome) later says written or refused with the edits taken back. A session is per connection: PumpAsync disposes it when the stream is closed, the connection ends, or the session throws (the client is then sent `ended`). Refusals: Unavailable when the connection or the table stream is not open (transient), PermanentRefusal.CannotOpen for a path that is not a designer document with a body, NotDeployed when no factory serves the origin; DesignerService is listed in PermanentRefusal.Tests NotARefusal with its reasons. Seen to fail: a server-streaming rpc added to the service (TheDesignerService_HasNoStreamOfItsOwn), a pump that does not dispose its session (two tests), a change sent under another stream id. NOT DONE here, by design: no client code uses these calls yet (tasks 12 to 16), so oneStreamPerTab passes unchanged and cannot yet fail for a table; no real session exists (the module's, task 17 onward); DiagramService.OpenSession still refuses a designer document on the diagram stream, which is right, since the client is to call OpenTable for it.

### API Endpoints

#### gRPC unary etalii.adp.DesignerService/OpenTable
- **Purpose:** Start a table stream on the connection's Watch under a client stream id
- **Location:** src/backend/EtAlii.Adp.Diagram/DesignerService.cs
- **Request Format:** OpenTableRequest { project_id, watch_id, stream_id, path }
- **Response Format:** OpenTableResponse {}; then WorkspaceMessage.table { stream_id, baseline | change | ended }

#### gRPC unary etalii.adp.DesignerService/CloseTable
- **Purpose:** End one table stream; idempotent
- **Location:** src/backend/EtAlii.Adp.Diagram/DesignerService.cs
- **Request Format:** CloseTableRequest { watch_id, stream_id }
- **Response Format:** CloseTableResponse {}

#### gRPC unary etalii.adp.DesignerService/SetTableWindow
- **Purpose:** Tell the session which lines are in sight
- **Location:** src/backend/EtAlii.Adp.Diagram/DesignerService.cs
- **Request Format:** SetTableWindowRequest { watch_id, stream_id, first, count }
- **Response Format:** empty; rows arrive as TableChange.rows

#### gRPC unary etalii.adp.DesignerService/SetTableView
- **Purpose:** Choose the view this connection shows
- **Location:** src/backend/EtAlii.Adp.Diagram/DesignerService.cs
- **Request Format:** SetTableViewRequest { watch_id, stream_id, view_id }
- **Response Format:** empty; TableChange.structure follows

#### gRPC unary etalii.adp.DesignerService/Edit
- **Purpose:** One gesture; accepted before it is written
- **Location:** src/backend/EtAlii.Adp.Diagram/DesignerService.cs
- **Request Format:** TableEditRequest { watch_id, stream_id, edit_id, gesture { kind, row_id, column_id, view_id, values, index, target_id, settings } }
- **Response Format:** TableEditResponse { error }; TableChange.outcome { edit_id, written, error, taken_back } follows
