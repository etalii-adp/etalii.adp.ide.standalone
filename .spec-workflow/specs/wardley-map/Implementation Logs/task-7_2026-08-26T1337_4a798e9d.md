# Implementation Log: Task 7

**Summary:** WardleyWriter: SetPosition, SetPipelineChildMaturity, SetPipelineExtent and Rename. THE CENTRAL DESIGN CHOICE IS THAT EVERY OPERATION SPLICES A SPAN INSIDE A LINE rather than rebuilding the line from the model, which is the difference between an edit and a reformat: a line rebuilt as `component Name [v, m]` silently loses the trailing comment, the decorators, the inertia flag, the label offset and whatever spacing its author chose, none of which the model carries positionally. There are tests for each of those survivals. The two numbers of a coordinate pair are replaced individually so the separator survives - `[0.80,0.40]` stays comma-tight and `[0.80, 0.40]` stays spaced - and numbers are written with format "0.####" so a hand-written file does not gain `1.0` where it said `1`. RENAME MATCHES BY SPAN, NEVER BY SUBSTRING REPLACE. In this notation a name containing another name is the norm rather than an edge case, and a naive replace renaming "Tea" would corrupt "Cup of Tea"; there is a test that fails the moment anyone reaches for String.Replace here. Rename rewrites the declaration, both ends of every link, the evolve, the pipeline parent and pipeline children in ONE pass, because Requirement 9.6's undo only restores them together if they moved together. A link to itself is handled right-to-left so replacing the source cannot shift the target's span out from under the second edit, and the evolve rename form keeps its arrival name (`evolve Datacentre->Cloud Hosting` renaming Datacentre must not touch Cloud Hosting). Every method REFUSES rather than guesses: an edit whose line no longer looks like the statement the model described returns false, so a caller reports a rejection instead of writing something wrong (Requirement 9.4). SetPipelineExtent refuses the nested form outright, which has no coordinates of its own, so the legacy form is written back as the legacy form (Requirement 5.4). One test re-checks the whole corpus still round-trips byte-identically with the writer in the picture, since the writer is only ever called on lines an edit touches. 17 writer tests. Verified: 1513 tests pass, format gate exits zero.
