# Implementation Log: Task 6

**Summary:** The strategy vocabulary: evolve with and without its rename form, the three attitude regions, accelerators and deaccelerators, notes, numbered annotations and url definitions. Requirement 6's whole surface. TWO SHAPES WERE CONFIRMED AGAINST THE REAL PARSER RATHER THAN GUESSED, AND BOTH WOULD HAVE BEEN WRONG. (1) An attitude's four numbers are [visibility1, maturity1, visibility2, maturity2] - visibility first, like everywhere else in this format. Reading them x-first would have put every pioneers/settlers/townplanners region on the wrong part of the map WHILE STILL LOOKING PLAUSIBLE, which is the worst kind of wrong. (2) Accelerators and deaccelerators are ONE collection distinguished by a boolean, not two lists; splitting them would invent a difference the format does not make. Also learned from the same probe: evolve's rename target is called `override` upstream and is empty when absent, and an annotation's positions are `occurances` (upstream's misspelling, recorded in a comment so the two are recognisably the same thing when someone reads the parser's output). Requirement 6.8's headline case works: WardleyAnnotation carries a list of occurrences, so `annotation 1 [[0.43,0.49],[0.08,0.79]]` keeps both positions and the single-position form is a list of one - the requirement left the representation open and insisted only that none be lost. ONE REAL BUG, caught by the corpus and now guarded: the comment stripper cut every line at `//`, which truncated `url x [https://...]` to `url x [https:` and parsed as nothing at all. A `//` preceded by a colon is a URL scheme, not a comment. The code comment claiming "the DSL has no string literal a // could hide inside" was WRONG - a URL is exactly that - and was corrected rather than left to mislead the next reader. Ordering detail worth keeping: `annotations` is matched before `annotation` because TryKeyword requires whitespace after the keyword, so the legend block's position would otherwise be tried as a numbered annotation; and evolve's arrow no longer reads as a link because of task 5's KnownKeywords guard. 25 vocabulary tests. Verified: 1496 tests pass, format gate exits zero.
