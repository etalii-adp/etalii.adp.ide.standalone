Discovery (1–6) is independently mergeable and useful on its own: after task 6 the backend logs every diagram type it carries at startup. The action half needs the contract change in task 7 on both sides before the client compiles, so do 7–16 in one continuous pass.

[`create-diagram-file`](../create-diagram-file/requirements.md) replaces that one branch; nothing else in this spec should need to change for it, and task 10's tests pin the check ordering that spec relies on.
