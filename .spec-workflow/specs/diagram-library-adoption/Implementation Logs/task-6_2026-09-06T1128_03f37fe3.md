# Implementation Log: Task 6

**Summary:** Migrated the rdf module's three sibling readings - SkosCanvas, OwlCanvas and ShaclCanvas - onto the diagram library, landed as merge c0fee53b (task commit 349079f1). Two library extensions carried the family: anchor-aware relation selection (RelationEndpointRule.anchors on the source names which anchors start that relation; relationFrom(element, anchor) picks it, so skos's TOP anchor files a concept under another while the SIDE anchor cross-links them - one gesture, two meanings) and DiagramModelConnection.className (per-connection class names joined into the connection group, for shacl's open edge-kind strings no definition can enumerate as relation types - one relation type "reference" plus shacl-edge-${kind} per connection).
