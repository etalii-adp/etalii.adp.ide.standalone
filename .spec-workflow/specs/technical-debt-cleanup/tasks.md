**Execution constraint (binding on every task below, not on writing this document): every task is implemented by an agent explicitly running the Fable 5 model** (the `Agent` tool's `model` parameter set to `fable`), per the design's dashboard-approved revision. A task picked up by an agent on any other model has not satisfied its own `_Prompt`.

**Order matters.** The eight groups below are R11's sequencing table, in the same order, smallest blast radius first. Each group is its own worktree (`.claude/worktrees/<name>`, short per CLAUDE.md's MAX_PATH note), its own merge to `develop`, gated independently - do not start group *N+1* before group *N*'s gate task has passed and merged. Group 7 depends specifically on group 6 (R12 before R3, per R12.1). **Requirement 7 has no group and no tasks**: the design records "extract nothing for the two measured roles, defer the rest" as a decision, and generating a task for it here would silently reverse that.

Before any group's worktree is created, check the dashboard's active specs against the module(s) that group touches, per R11.3 - this is a manual step in each group's first task, not automated.
