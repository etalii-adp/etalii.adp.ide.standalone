## Artifacts

### Classes

#### RegistrationLayout
- **Purpose:** Core reader/writer for the .adp layout: block - authored positions as registration metadata, never in the body file. Block format: 'layout:' after the MIME line and key:value headers, then indented '<element-id>: <x> <y>' entries, invariant culture. Preserves all non-block bytes including per-line terminators; the block itself is normalized CRLF. Defined once in core for every module.
- **Location:** src/backend/EtAlii.Adp.Backend/Hierarchy/RegistrationLayout.cs
- **Methods:** Read(adpPath) -> IReadOnlyDictionary<string, RegistrationPosition>, Apply(computed, stored) -> merged positions, stored wins element-by-element, stale ids override nothing, SetPosition(adpPath, elementId, position) -> prior RegistrationPosition? (null when absent) for command inverses, RemovePosition(adpPath, elementId) - removing the last entry removes the block, Prune(adpPath, liveElementIds) - drops stale entries on the next write
- **Exported:** No
