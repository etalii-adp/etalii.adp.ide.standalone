Why the `IEditorSessionFactory` parameters were marked, not removed:
- The interface is the documented extension seam for editor modules ("The backend seam is IEditorSessionFactory", docs/creating-an-editor-module.md).
- It deliberately mirrors the diagram factories' `Open(watchId, rootPath, ...)`.
- Its own summary says a module is "handed the root and path".

This follows the brief's interface-contract exception. The attribute sits on each parameter, because ReSharper honours `[UsedImplicitly]` on a parameter. Removal is still possible: it would mean changing the two editor factories, the Backend.Tests throwing fake, the three `DiagramService.Open` call sites, and the module doc.
