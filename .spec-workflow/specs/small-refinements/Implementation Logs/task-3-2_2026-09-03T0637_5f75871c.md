**Summary:** Added the three-valued state and its single decision point. EntryDiagramState (own _Model file, namespace level): Unspecified = 0 (neutral, deliberately proto3's default for a field added to an existing message), Registered = 1, Potential = 2. EntryNode gains DiagramState with a defaulted constructor parameter so every existing construction compiles and reads neutral. EntryDiagramStates.Decide is one pure function over the name set the folder scan already holds (siblings for a file, contents for a folder) plus four delegates: the scan's own resolvedBodyNameOf, DiagramFileRouter.ClaimsExtensionOf, EditorResolver.IsClaimed, and declaresFolderSubject. File rules in order: itself an .adp → Registered; a same-named sibling .adp or a sibling registration whose body resolution lands on this file → Registered; a diagram type claims the extension → Potential; a non-fallback editor claims it → Potential; otherwise Unspecified. Folder rules: Registered when a contained registration declares a folder subject (the registration lives INSIDE the folder per the design's correction of Requirement 3.1's parenthetical), otherwise Unspecified — never Potential. No filesystem access anywhere in the decision.
