# Implementation Log: Task 5

**Summary:** ScalarConversion (Rules/ScalarConversion.cs) is the conversion table of FBL 0.5 section 5.2 and replaces TypedValue and BodyReading.Mistyped: an int from a long or a finite double with no fraction, a number from a long or a double, a bool from a bool, the date, time and other types as before. A quoted YAML scalar converts to a number or a bool only with quoted: convert, from its written text; a JSON string never does. A typed slot with nothing written is absent, so its default applies. A value that does not convert takes the binding's fallback and is reported as fbl.unconverted-value (a warning) at its span, with the attribute and the written text in Finding's new Detail, unless the fallback says report false; without a fallback the entry is unreadable, as before. YamlFamily.Format keeps the quotes of a number replacing a quoted scalar under quoted convert. ScalarConversion.Tests replaces TypedValue.Tests case for case and adds the 5.2 table cell by cell; YamlWriting.Tests gains the unconverted-bytes and kept-quotes tests; each seen red first (red runs kept). The Knowledge designer shows no difference. The inspector's two findings (a float equality, a UTF-8 literal) were fixed before the push and the inspector is clean.
