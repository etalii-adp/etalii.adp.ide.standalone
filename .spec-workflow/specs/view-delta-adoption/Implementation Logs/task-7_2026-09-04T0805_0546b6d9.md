### Functions

#### DatabricksElementMapper.Visible
- **Purpose:** Culls a rendering to a reported viewport: every box that intersects it, plus - one hop exactly - the far end of any edge with one end already in view, so a connector is never drawn to a box that was culled. Edges carry no position (all three readings pack one at the origin), so their endpoints decide them, read back from the DatabricksEdgePayload this mapper wrote. The hop is taken against a snapshot of the in-view set rather than the growing set, so the answer does not depend on the order edges arrive in.

#### viewBoxOf
- **Purpose:** Converts the module's DatabricksView (startX, startY, pixelsPerUnit) into the ViewBox the shared report hook keys on: origin plus span in canvas units, where span is the surface's pixels over the zoom. Keying on these four numbers makes a zoom and a surface resize each count as a view change, which they are.
