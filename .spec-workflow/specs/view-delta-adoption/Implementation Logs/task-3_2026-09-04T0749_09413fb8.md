# Implementation Log: Task 3

**Summary:** helm-charts closes the view-delta loop, both halves. Backend: HelmSession gains a _viewport field defaulting to DiagramViewport.Unbounded (so a client that never reports still sees the whole chart it got at baseline) and UpdateView now diffs the visible set across the viewport change — Add for what appeared, then Remove for what left, the order both reference sessions emit in and the opposite of Requirement 4.3's guess. The visibility decision is a new module-local HelmElementMapper.Visible that keeps the Ansible module's one-hop rule verbatim: an edge with one end in view brings the other end with it, so a connector always has both boxes to be drawn between, and an edge whose target never resolved still draws from its source to nothing. No shared backend helper was written — helm is the third consumer of that shape, and the design's rule is that extraction happens on three consumers wanting the same behaviour, not on resemblance, so it was raised rather than taken. Render() and UpdateView now share a private Boxes() helper so the render and the view diff can never disagree about where an element sits; Render() is viewport-aware, which keeps a chart-change push consistent with the narrowed set. The class remarks that declared the diagram had nothing to virtualize are replaced with what the code now does. Client: useHelmStream exposes reportView via the shared viewReportOf; HelmCanvas drops its private ViewBox interface for the shared one and wires useViewReport with its effective view, a viewRef mirror and the svg surface ref — passing box plus surface, measuring nothing itself. Two tests that asserted the old declined-to-virtualize behaviour were inverted rather than deleted, each carrying a line saying what it used to assert and why that changed.
