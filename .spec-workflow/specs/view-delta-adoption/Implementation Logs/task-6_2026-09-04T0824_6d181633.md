# Implementation Log: Task 6

**Summary:** Guarded the interaction between a narrowed viewport and a document edit in dependency-graph, and fixed the path disagreement the guard exposed. The module's OnDocumentChanged was already viewport-aware, so the warned-about bug (a change path rendering unfiltered and silently re-sending culled elements) was not present; the test proving it was. Writing that test surfaced a second form of the same fault: UpdateView computed its own before-and-after set and never updated _delivered, so after a narrowing the change path still diffed against the whole graph and emitted a Remove for elements the client had dropped moments earlier. UpdateView now runs the same Render and the same Diff the change path runs — the shape timeline uses — so the two paths cannot hold different ideas of what the connection has. The fix removed more code than it added (27 lines out, 19 in).
