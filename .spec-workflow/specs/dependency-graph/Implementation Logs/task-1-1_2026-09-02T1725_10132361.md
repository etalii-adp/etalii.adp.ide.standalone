# Implementation Log: Task 1.1

**Summary:** Forked the timeline's document layer into EtAlii.Adp.Diagram.DependencyGraph with every date deleted. An element is id/label/x/row where x is a plain canvas number; a relation is a directed from/to depends-on; the version marker is `dependencies: 1` and the sections are `elements:`/`relations:`. TimelineInstants and TimelineScale have no counterparts. The writer keeps the timeline's splice-only discipline, so an unchanged .dgr round-trips byte-identically and one edit changes only that element's lines. Eleven fresh .dgr fixtures with believable service-dependency content, plus a `*.dgr -text` line in the root .gitattributes because the corpus byte-compares mixed line endings the way .tml's does.
