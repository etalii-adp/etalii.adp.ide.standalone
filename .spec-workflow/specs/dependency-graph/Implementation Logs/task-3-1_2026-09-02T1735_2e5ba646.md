# Implementation Log: Task 3.1

**Summary:** Forked the timeline client. TimelineRuler and timelineTicks have no counterparts - naming times was their whole job - so the canvas has no fixed bottom strip and the scrollbars sit lower to fill it. The view window is startX/pixelsPerUnit in plain canvas units; a node's box is a fixed 160 canvas units wide where the timeline derived width from a duration; drag hints read "x · row". Resize is gone with the duration it resized: no onResizeStart is wired and the shared component's adorner strips are hidden through the module's own class, leaving the timeline untouched. Every edge gains an SVG arrowhead at its `to` end through a marker defined in this canvas's defs and attached by marker-end in this module's stylesheet - so the shared InteractiveBezierConnection needed no change either. The scroll view is a temporary fork of TimelineScrollbars carrying a comment pointing at small-refinements' pending extraction, since that has not landed. 29 canvas tests plus the model and registration suites; the client's generate script gained the module's api folder.
