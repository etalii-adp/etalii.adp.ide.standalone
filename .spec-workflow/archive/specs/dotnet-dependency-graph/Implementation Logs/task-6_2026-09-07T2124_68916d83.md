# Implementation Log: Task 6

**Summary:** DotNetContextPropertyProvider, every row read-only (Requirements 4.1-4.4, 5.1). Project rows: name, path, target framework or frameworks, .NET version. Package rows: package id, version or versions, a conflict row where the projects disagree, and the description. Every row carries a non-empty ReadOnlyReason in the house shape - cause first then remedy, naming what would have to change instead - and for this type the remedy is never in ADP, because the whole subject belongs to the build. SetAsync refuses even though ContextPropertyResolver already refuses server-side: a provider that would accept a write if the resolver ever changed is a trap rather than a design.

ONE DELIBERATE DEPARTURE from the ansible provider this design names as its precedent. That one DROPS a row it has nothing to put in; this one SHOWS the absence. Requirement 4.4 asks for the absence to be visible, and a missing row reads very differently from a missing value to a reader wondering whether the diagram simply failed to look. So a project on netstandard2.0 carries a .NET version row saying "Not discoverable", and a package the local NuGet cache has never seen carries a description row saying so - the cost of the cache-only decision made visible where a user actually meets it, rather than as a blank field indistinguishable from a package with no description of its own.

The conflict row is PAIRED with a test proving it stays away when there is no conflict: an assertion that a row appears proves nothing about the condition that produces it unless something also proves its absence - the same pairing rule the abandon-versus-commit tests follow elsewhere in this repository. All three mechanisms seen to FAIL first: with the read-only reason blanked and each absence rendered as an empty string, three tests went red.

IDependencyGraphStore was introduced here as the seam the provider reads through, so this task is testable against a graph rather than a disk; task 7 supplied the implementation. The test project gained a reference to EtAlii.Adp.Context for the provider seam. 50/50 green at the time of this task. Worktree commit 30cd8493 on claude/ddg.
