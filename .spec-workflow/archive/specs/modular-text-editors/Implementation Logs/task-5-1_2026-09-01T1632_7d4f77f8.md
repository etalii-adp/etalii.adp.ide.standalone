# Implementation Log: Task 5.1

**Summary:** Added CodeMirror 6 (chosen over Monaco per design: modular per-language packages, no worker/Vite config) plus the shared base editor component BaseTextEditor and the stream-folding hook useEditorText. BaseTextEditor owns one EditorView with line numbers, history, a Mod-s keymap dispatching onSave, and an updateListener firing onChange; external content is applied only when it differs from the view's doc, so user keystrokes never bounce. scrollToLine(host, line) exports the go-to mechanism. useEditorText folds the shared diagram stream (useDiagramStream from technical-debt-cleanup) into {text, revision, loaded} by taking the payload of any arriving "content" add-element (the Remove half of the backend's Remove+Add replacement pair is ignored).
