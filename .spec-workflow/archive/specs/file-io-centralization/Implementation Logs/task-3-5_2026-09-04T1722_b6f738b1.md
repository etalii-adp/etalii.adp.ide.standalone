# Implementation Log: Task 3.5

**Summary:** Converted RdfDocumentStore's user-document read from File.ReadAllText to SharedDocumentReader.ReadAllText, and removed the module's line from the tracked allow-list in the same change. One read site serves four readings: RdfDocumentStore is the single store behind rdf, owl, skos and shacl — their four sessions, four factories and a dozen command classes all consume IRdfDocumentStore — so the module offended once rather than four times, and one line fixes it for all of them. The File.Exists check was deliberately kept, because SharedDocumentReader opens with FileMode.Open and would throw on a body that does not exist yet; a missing body is an empty document, not an error.
