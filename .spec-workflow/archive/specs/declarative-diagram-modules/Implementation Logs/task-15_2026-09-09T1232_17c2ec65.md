# Implementation Log: Task 15

**Summary:** The conformance guard: one test that walks every diagram module's client and fails once, naming every offender with its file, its rule and the line as written. The standard the tree already carried was unasserted, so it drifted - twenty-eight element types used the function-valued escape hatch and zero used the declarative vocabulary beside it. Nobody decided that; each canvas was written by copying the one before it. Three text rules (a module-supplied renderer, a hand-written structural key list, a synthesised key event) plus a fourth checking every named shape is in BUILT_IN_SHAPES. It reports every offender at once rather than the first, because a guard that stops at the first turns one afternoon's work into five. Two canaries stand between it and passing vacuously: a floor of 40 module client files walked, and a named member (wardley-map/client/WardleyCanvas.tsx) it must have seen - neither alone is enough, since a floor is defeated by a glob pointing at the wrong tree and a name by a walk that stops early. Its limit is stated in its own doc-comment: it reads text, so a renderer under an unrecognisable name goes unseen. That limit is acceptable because it is not how this happens - what happens is a copy, and a copy carries the shape it was copied from.
