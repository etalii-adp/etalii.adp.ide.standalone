# Implementation Log: Task 6

**Summary:** The structural half of the model, sent shaped (Requirements 5.1-5.4).

The mapping is the same five facts in every module - identity, type, position, size, and an edge's two ends - and every module writes them differently. dotnet-dependency-graph PARSES an edge's ends out of the element id; others read them from their payload; each hard-codes a size constant and the definition's element-type id in its canvas. That is what the 665 lines are.

So the wire carries them now: Size2D, element_type, and source/target ids with their anchors, all OPTIONAL additions to Element. A shared structuralModelOf turns wire elements into a DiagramModel with no module code at all.

THE ENDPOINTS ARE THE DISCRIMINATOR, and that is what lets this live in one place. An element naming two ends is an edge and one that does not is a node, in every notation - so the split happens here rather than in thirteen canvases with thirteen rules. A half-declared edge is a node, because one end is not a connection.

THE SEMANTIC HALF DELIBERATELY DOES NOT CROSS. Which payload field is the header, which collection are the rows, which flag drives a status colour - that is each module's own vocabulary. Putting it on the wire would mean a .proto deciding presentation, inverting the dependency structure.md sets. The user ruled for this split on 2026-09-08 with the alternative in front of them, and the design flagged the nuance rather than absorbing it.

TWO RULES CHOSEN DELIBERATELY. An absent size stays ABSENT rather than becoming 0x0: a zero size is a drawn point while an absent one lets the type's sizing rule decide, and sending 0x0 for "unknown" would draw every unmigrated element as nothing. And a connection whose ends have not both arrived is still EMITTED - the canvas already declines to draw a connector to an element it does not hold, and dropping it here would hide a delivery order that may legitimately resolve on the next delta.

INERT UNTIL A MODULE FILLS THE FIELDS. An element setting none of them maps to what its module builds by hand today, because element_type falls back to the mime-style type - so the twelve unmigrated modules are unaffected. payloadOf is the one thing a module still supplies, and it DECODES rather than maps: it knows how to read its own Any and nothing here does.

The backend was rebuilt against the changed contract rather than assumed to be fine. The additions are optional so it compiles - but a codegen break is invisible to a cached gate by construction, which is exactly the case the fresh-tree rule exists for.

Sabotages: a missing size becoming 0x0, and one end being enough to call something a connection. Each reddens only its own fact. 1200 client tests across 117 files, typecheck zero, backend build zero.
