# Implementation Log: Task 1

**Summary:** Added DiagramRegistrationName, the registration naming convention of Requirement 1: subject.adp, subject.qualifier.adp, and the bare .adp that registers its folder. It deliberately does not choose between the two readings of an ambiguous name (my.config.adp is subject my.config, and equally subject my with qualifier config) — it reports FullBase and SubjectBase and leaves the choice to derivation, which can look at disk. A folder-scoped name is a distinct state rather than an empty base, so Requirement 4.4's exclusion is structural. DiagramFileName.Sanitise became public so a qualifier is validated by the one sanitiser a base name already uses (Requirement 1.4); the period is sanitised because it is this convention's own separator. A leading dot is not a separator: .hidden.adp is the subject .hidden.
