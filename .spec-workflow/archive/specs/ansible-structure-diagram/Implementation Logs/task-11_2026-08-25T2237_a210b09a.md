# Implementation Log: Task 11

**Summary:** AnsibleGraph.Derive(project) - a pure function, no file access, no clock - producing nodes and the five edge kinds, plus five _Model types (AnsibleEdge, AnsibleEdgeKind, AnsibleTargetResolution, AnsibleNode, AnsibleNodeKind). Beyond the task's file list I added AnsibleNode/AnsibleNodeKind: the layout (task 13) is keyed by node id and the mapper (task 15) needs node identity, so the graph has to expose nodes as well as edges. Node ids are as the design specifies: playbook:site.yml, play:webservers.yml#0, role:nginx, taskfile:roles/nginx/tasks/tls.yml, inventory:inventories/production, vars:.../group_vars. Decisions worth recording. (1) A play is its own box ONLY when its playbook has more than one - a single-play file drawn as both a playbook box and a play box would say the same thing twice - so edges from a single-play playbook run from the playbook node. Requirement 4.1 says "within a playbook, when a playbook has more than one" and this is that read literally. (2) include_role/import_role appearing inside a ROLE's tasks produce a UsesRole edge, not an IncludesTasks one: a role reaching for another role is the same relationship a play's roles: list declares. (3) Task files become nodes only when something includes them, so they are added while include edges are derived rather than up front - nginx has two task files and only tls.yml is a node. (4) Host-pattern matching is a deliberate subset - union separators, all/*, trailing glob - and exclusions (!group) and intersections (&group) draw NOTHING: an exclusion names what a play will not run on, so an edge for it would say the opposite of what the file says. A pattern no inventory defines yields no edge at all; the rule set reports it instead (task 18). (5) Path resolution for import_playbook and include_tasks is relative to the declaring file's folder, with . and .. collapsed in-memory - no disk access, so the graph stays pure. (6) AnsibleEdge.Id uses the target AS WRITTEN rather than the resolved id, so a missing and an unresolvable edge still have identity and an edge keeps its id when the role it names finally appears. One test-authoring mistake caught before building: an assertion I wrote as `Assert.Equal(...) is var _ when ... || true` asserted nothing; replaced with real per-source assertions on the pattern label. 30 new tests (63 total in the module), all passing first run. Verified: build 0 errors; module 63/63; no regression across Backend 494, Diagram 62, Mindmap 146, C4 393. Phase C is complete.
