# Implementation Log: Task 6

**Summary:** ProblemMaintenance.RevalidateAsync's NotADiagram branch now walks up from the changed path to the nearest .adp whose definition has a folder subject and validates that diagram's scope instead, via a new private EnclosingFolderDiagram helper. Two refinements beyond the task text. First, performance: the task promised "one directory probe per changed file", which a level-by-level walk cannot honour, so instead the walk does not start at all unless some discovered type actually has a folder subject - a new DiagramFileRouter.HasFolderSubjectTypes property over the catalog it already owns. Every deployment before ansible/structure ships therefore pays one list scan and zero filesystem access, which is stronger than what was promised. Second, correctness: ProblemPathsUnder adds every path currently carrying a problem inside that folder to the covered set, so a fix is cleared even when the problem had been attributed to a different file of the same diagram - without it, only the edited file's own entries would clear and a fixed problem elsewhere in the tree would survive. The walk stops at the project root, reads only .adp files, orders candidates ordinally so a folder holding two folder-subject registrations always resolves the same way, and returns null on IOException/UnauthorizedAccessException so a folder deleted mid-walk costs nothing. Guards: AChangeInsideAFolderDiagram_RevalidatesThatDiagram (asserts the folder validator ran, was handed the folder as SubjectFolder rather than one MIME line, and that both the .adp and the edited file are covered) and AChangeOutsideAnyFolderDiagram_IsStillIgnored (the walk must not turn every stray file into a validation). A new ProblemMaintenanceFolderValidator stub reads SubjectFolder and reports a file-located problem, which is what a real folder-subject rule set does. VERIFIED THE GUARD IS REAL: temporarily returning null from EnclosingFolderDiagram makes AChangeInsideAFolderDiagram_RevalidatesThatDiagram fail (1 failed of 494) and restoring it returns all 494 to green - the test does not pass for the wrong reason. Phase B is complete: all three core seams plus the maintenance walk-up are in.
