# Implementation Log: Task 21

**Summary:** ansibleModel.ts (decode + applyDelta + nodesOf/edgesOf/anchorsOf/paletteSlotOf) and useAnsibleStream.ts, with 13 tests. Two absences are the design, and both are pinned. (1) applyDelta handles TWO delta cases where the mindmap's handles four: nothing on this diagram folds, so the backend never emits group or ungroup, and the client ignores them rather than handling them - one arriving means something upstream is confused, and doing nothing beats inventing fold state a read-only diagram has no use for. The model consequently has no `folded` map at all. (2) useAnsibleStream exposes NO moveElement. The backend refuses one with a sentence (task 16), so offering the call would put a gesture in the client's reach whose only possible outcome is a refusal; a test asserts the hook's source does not contain it. That test reads the function source rather than rendering the hook, because the claim is about the surface and rendering would need a React renderer and a live transport to prove something structural. anchorsOf returns null when either end is out of view rather than drawing to nowhere, which pairs with the backend's viewport-plus-one-hop rule: the backend guarantees both ends arrive together, and the client degrades safely if that ever stops being true. paletteSlotOf wraps the play index into however many slots the stylesheet defines, and returns -1 for a node belonging to no play - the palette itself stays in CSS, so a theme change is a stylesheet change rather than a protocol one. Environment note repeated from task 14, since it bit again: a fresh worktree has no node_modules, so npm install (142 packages, ~3s) then npm run generate is needed before the client typechecks or tests.
