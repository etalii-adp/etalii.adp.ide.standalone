# Implementation Log: Task 22

**Summary:** AnsibleCanvas.tsx and ansible-structure.css, with 15 component tests. The canvas is markedly smaller than MindmapCanvas (roughly 400 lines against 731) and the difference is all absence: no drag, no drop target, no toolbox, no context-menu commands, no keyboard mutation - because this type has none of those to offer. Pan and zoom remain, and a drag on empty canvas pans, which is free precisely because no element can be moved. Decisions: (1) EVERY colour and shape is in the stylesheet, including the per-play palette - the wire carries an index and CSS decides what it means, so a theme change is a stylesheet change rather than a protocol one. A test asserts the rendered canvas contains no element with an inline style at all. (2) Each node kind gets its own outline weight or dash in addition to its fill, so colour is never the only thing carrying the distinction. (3) An edge whose target is missing or unknowable is drawn as a STUB from its source rather than not drawn: a reader has to be able to see that a playbook names something that is not there. Missing and unresolvable are labelled differently ("(missing)" vs "(expression)") because missing is a mistake and unknown is not - the three-state resolution finally reaching the screen. (4) Activation is bound to double-click AND Enter/Space: the jump from picture to file is most of what this type is for, and a keyboard reader should not have to reach for the mouse to use it. (5) Three states before there is anything to draw - loading, failed, and an empty model that explains where this type looks (root, playbooks/, roles/, inventories/) rather than showing a blank canvas that would read as broken. That last one matters because "undrawn" is a valid answer for an unrecognised layout, and a bare empty canvas would not say so. The most valuable test is OffersNoEditingAffordanceOfAnyKind, asserting no draggable, no drop target, no input/textarea/contenteditable and no toolbox - the type's whole statement, asserted rather than left to inspection.
