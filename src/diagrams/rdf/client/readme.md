# rdf client

One set of canvases for the family's four readings - `w3c/rdf`, `w3c/owl`, `w3c/skos` and
`w3c/shacl` - over one stream shape.

## Inline renaming

**Exempt across all four readings, not pending: the drawn labels are derived.** What these
canvases draw is a prefixed name computed from an IRI - `ex:Kettle` for
`http://example.org/t#Kettle` - and changing it renames that term across the whole document,
with collision and prefix rules whose refusals need more room than a textbox has. That is the
module-authoring guide's own worked example of a label that must NOT be marked: a different
act from retyping a caption, correctly kept on the dialog where its validation can speak. The
same holds for every reading's variants - a SKOS concept's prefLabel row is a property edit,
an OWL expression's text is a rendering of structure. Nothing here is waiting on a gesture;
the exclusion is the feature's own rule applied, not a gap.
